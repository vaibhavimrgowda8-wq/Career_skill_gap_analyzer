Career Skill Gap Analyzer

Project Description

Career Skill Gap Analyzer is an AI-powered web application that analyzes a user's existing skills and identifies skill gaps based on their desired job role.

Features

- Skill gap analysis
- Career recommendations
- Identification of missing skills
- Personalized learning guidance

Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript

Installation

1. Clone this repository.
2. Install dependencies:
   "pip install -r requirements.txt"
3. Run the application:
   "python app.py"
